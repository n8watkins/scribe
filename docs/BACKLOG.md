# Backlog

Ideas that are written down but not planned to be built.

## Not planned

### Per-app or per-project custom words

Not planned: keeping a set of custom words for each app or project is too much list management.

The idea was to send a different short set depending on where you dictate, for example:

- VS Code on the n8builds repo (n8builds, Appturnity, Tauri, worktree);
- Slack (teammates' names);
- an email (client names).

Scribe could tell the app from the focused window's process name, and the project from its window title.
It may not generalise anyway, because most people have one vocabulary that one set of 35 to 40 terms covers.
Reconsider only if the custom words budget is regularly full for real users and a held-out test shows that the terms left out to make room are then missed.
